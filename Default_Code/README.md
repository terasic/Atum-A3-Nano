# Atum A3 Nano Factory Configuration

This is the default configuration bitstream for the Atum A3 Nano board, demonstrating some of its basic features.

## Description

The Atum A3 Nano board is pre-programmed with a default configuration. This demonstration makes the four user LEDs blink and displays an image of the board on an HDMI monitor. The project includes several batch files for programming: `test.bat` programs the `.sof` file to the FPGA, `flash_program.bat` programs the `.jic` file to the flash, and `convert.bat` converts a `.sof` file to a `.jic` file before programming it to the flash.
