# Golden Top Project

A trusted, pre-configured Quartus template project for the Atum A3 Nano, providing a correct hardware configuration starting point to accelerate development.

## Description

The Golden Top Project is Terasic's official Quartus template, designed to accelerate development and reduce configuration errors. It provides a verified project foundation with all pin assignments (`.qsf`) and I/O standards pre-configured for the board's components, including LEDs, buttons, SDRAM, and external interfaces.

Developers can copy this project to bypass tedious manual setup and begin designing their core logic immediately.
